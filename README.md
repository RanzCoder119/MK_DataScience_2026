## 🎯 Kesimpulan Perjalanan Belajar Data Science Pertemuan 1–13

Tiga belas pertemuan mata kuliah Data Science ini membawa saya dari nol hingga mampu membangun pipeline machine learning dan deep learning secara mandiri. Perjalanan dimulai dari memahami ekosistem Python (NumPy, Pandas, Matplotlib), lalu berkembang ke EDA dan visualisasi yang membantu saya "berbicara dengan data" secara visual.

Pertemuan 4 dan 5 membuka mata saya terhadap supervised learning — bagaimana mesin dapat "belajar" dari data berlabel untuk membuat prediksi. KNN mengajarkan prinsip similarity-based learning, sementara Decision Tree menunjukkan bahwa model yang baik tidak harus kompleks — cukup interpretable dan akurat. Pertemuan 6 melengkapi pemahaman dengan unsupervised learning melalui K-Means, membuktikan bahwa mesin dapat menemukan pola tanpa label apapun.

Pertemuan 7 menjadi pintu gerbang machine learning sejati — saya membangun pipeline Regresi Linear end-to-end dengan R² > 0.90, memahami bahwa preprocessing dan feature engineering menentukan 80% keberhasilan model. Pertemuan 9 dan 10 memperdalam supervised learning dengan Logistic Regression, Decision Tree, Random Forest, dan Naive Bayes — saya belajar bahwa memilih metrik evaluasi yang tepat (Recall untuk kasus medis & churn) lebih penting daripada sekadar mengejar akurasi.

Pertemuan 11 menghadirkan unsupervised learning yang lebih kaya dengan Hierarchical Clustering dan dendrogram — saya memahami trade-off antara partitional (K-Means, cepat) dan hierarchical (lambat tapi informatif). Pertemuan 12 membuka dunia sistem rekomendasi: Association Rules (Apriori) untuk pola transaksi dan Content-Based Filtering untuk kemiripan item — fondasi penting untuk memahami bagaimana Netflix, Spotify, dan Amazon merekomendasikan produk.

Puncak perjalanan di Pertemuan 13 — saya menyentuh Deep Learning dengan TensorFlow/Keras dan NLP dengan TF-IDF. Neural network sederhana mengungguli Logistic Regression pada dataset non-linear (97% vs 83%), dan visualisasi decision boundary memberi intuisi kuat tentang kekuatan representasi non-linear. Klasifikasi sentimen dengan TF-IDF + Logistic Regression menunjukkan bahwa model klasik tetap relevan karena interpretable dan efisien.

**Pembelajaran terpenting:** Data science bukan sekadar tentang algoritma — proses EDA, visualisasi, dan preprocessing yang matang justru menentukan 80% keberhasilan model. Pemilihan metrik evaluasi yang sesuai konteks bisnis (Recall untuk medis/churn, Silhouette untuk clustering, Lift untuk association rules) lebih kritis daripada mengejar satu angka akurasi. Saya berencana melanjutkan eksplorasi ke transformers (BERT, GPT) dan deploy model ke produksi dengan FastAPI/Docker.
